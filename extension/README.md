# Google Snake - Quick Play

A Manifest V3 Chrome extension that embeds https://www.googlesnake.com/ inside the extension popup.

This version uses explicit CSS `display` changes instead of the HTML `hidden` attribute.

## Install

1. Open `chrome://extensions`
2. Enable Developer mode
3. Click Load unpacked
4. Select this folder

## Usage

Click the extension and then click **Play Google Snake**.
